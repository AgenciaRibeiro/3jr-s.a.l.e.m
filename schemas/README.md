# Fichas mestres — modelos

Estes são modelos **genéricos**, sem registros reais. Use URLs/IDs confirmados somente em repositórios ou bases com classificação de acesso apropriada.

Padrões propostos:

- `ASV-0001`: assistente virtual.
- `CLI-0001`: cliente.
- `CON-0001`: integração/API/MCP.
- `VPS-0001`: servidor.
- `REPO-0001`: repositório.
- `FLUXO-0001`: workflow.

É proibido inserir tokens, segredos, contratos, dados pessoais ou dados confidenciais nos modelos de exemplo.
